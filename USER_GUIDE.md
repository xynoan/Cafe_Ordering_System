# User Guide

This guide explains how to use the Cafe Ordering System for all user types: Customers, Employees, and Managers.

## 🚀 Getting Started

### First Time Setup
1. Launch the application
2. The main login screen will appear
3. Choose your user type (Customer, Employee, or Manager)
4. Sign up for a new account or log in with existing credentials

## 👤 Customer Guide

### Registration & Login

#### Creating a Customer Account
1. Click on the **Login** button
2. Select **Customer** from the login options
3. Click **Sign Up** if you don't have an account
4. Fill in your desired username and password
5. Click **Submit** to create your account
6. You'll be redirected to the login screen

#### Logging In
1. Select **Customer** login option
2. Enter your username and password
3. Click **Login**

### Using the Menu System

#### Browsing the Menu
- The menu displays all available items with:
  - Product name
  - Price
  - Available stock
  - Product image
- Items are categorized (coffee, tea, pastries, etc.)

#### Placing Orders
1. Browse through the available menu items
2. Click on items you want to order
3. Specify quantities if available
4. Review your selections
5. Confirm your order
6. Your order will be processed

#### Providing Feedback
1. After placing an order, you can access the feedback system
2. Rate the service (1-5 stars)
3. Select the product you want to review
4. Rate the specific product (1-5 stars)
5. Add optional comments
6. Submit your feedback

### Navigation Tips
- Use the navigation buttons to move between screens
- The **Back** button returns to the previous screen
- **Logout** returns you to the main login screen

## 👩‍💼 Employee Guide

### Employee Access

#### Logging In
1. Select **Employee** from login options
2. Enter your employee username and password
3. Enter the **Employee Verification Code** when prompted
4. Access granted to employee dashboard

> **Note:** The employee verification code is provided by management

### Menu Management

#### Adding New Products
1. Navigate to **Add Product** section
2. Fill in product details:
   - **Product Name**: Enter the item name
   - **Price**: Set the selling price
   - **Stock**: Initial quantity available
   - **Image**: Optional product image path
3. Click **Add Product** to save

#### Removing Products
1. Go to **Remove Product** section
2. Enter the exact product name to remove
3. Click **Remove Product**
4. Confirm the action

#### Updating Product Information
1. Access **Update Product** section
2. Search for the product by name
3. Modify the following as needed:
   - Price
   - Stock quantity
   - Image path
4. Save changes

### Inventory Management

#### Checking Stock Levels
- View current stock for all products
- Identify items that need restocking
- Monitor product availability

#### Stock Updates
1. Select the product to update
2. Enter new stock quantity
3. Save changes
4. Stock levels update in real-time

### Order Processing

#### Viewing Orders
- Access customer orders as they come in
- See order details and customer information
- Track order status

#### Managing Order Queue
- Process orders in chronological order
- Update order status as items are prepared
- Communicate with customers about order progress

## 👨‍💼 Manager Guide

### Manager Access

#### Logging In
1. Select **Manager** from login options
2. Enter your manager username and password
3. Enter the **Manager Verification Code**
4. Access granted to manager dashboard

### Employee Management

#### Adding New Employees
1. Navigate to **Employee Management**
2. Click **Add Employee**
3. Fill in employee details:
   - Username
   - Password
   - Initial salary
4. Click **Submit** to create the employee account

#### Viewing Employee List
- Access complete list of all employees
- View employee information:
  - Username
  - Salary
  - Status (Active/Inactive)

#### Updating Employee Information
1. Select employee from the list
2. Modify employee details:
   - Salary adjustments
   - Status changes
3. Save changes

#### Removing Employees
1. Select employee to remove
2. Confirm deletion
3. Employee account will be deactivated

### System Analytics

#### Viewing Feedback Reports
1. Access **Feedback Management**
2. View customer feedback by:
   - Service ratings
   - Product ratings
   - Customer comments
3. Filter feedback by:
   - Date range
   - Product category
   - Rating level

#### Product Performance
- Monitor which products are popular
- Track sales trends
- Identify slow-moving items

#### System Ratings Overview
- Overall service rating average
- Product-specific ratings
- Customer satisfaction trends

### Administrative Functions

#### Code Management
- Update employee verification codes
- Update manager verification codes
- Ensure security of access codes

#### System Configuration
- Modify system settings
- Update product categories
- Configure pricing rules

## ❓ Troubleshooting

### Login Issues

#### Forgot Password
1. Contact system administrator
2. Password reset must be done by manager
3. Provide username for verification

#### Access Code Problems
- Verify correct code entry
- Check with management for current codes
- Ensure proper user role selection

### System Performance

#### Slow Loading
- Check internet connection
- Close unnecessary applications
- Restart application if needed

#### Error Messages
- Read error message carefully
- Check data entry for accuracy
- Contact support if problem persists

### Data Issues

#### Missing Products
- Check if product was removed
- Verify spelling in searches
- Contact employee/manager for assistance

#### Incorrect Pricing
- Report to employee or manager
- Pricing updates require employee access
- Changes reflect immediately after update
